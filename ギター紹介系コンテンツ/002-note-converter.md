# Skills 002: note記事変換

## 基本情報

| 項目 | 内容 |
|---|---|
| **Skill名** | `note-converter` |
| **カテゴリ** | 記事執筆系 |
| **発動条件** | 「noteの記事に変換して」「note用に整形して」と言ったとき |

## 概要

X記事で書いた内容を、noteのフォーマットに最適化された形に変換するSkill。

### XとnoteのフォーマットFの違い

| 項目 | X記事 | note記事 |
|---|---|---|
| 文体 | 短文・フック重視 | 丁寧・読了率重視 |
| 改行 | 多め | 適度 |
| 目次 | なし | あり |
| 冒頭 | フック | 要約文 |

---

## SKILL.md 本体

```yaml
name: note-converter
description: >
  X記事の原稿をnoteフォーマットに変換する。
  「noteの記事に変換して」「note用に整形して」と言われたら発動。
```

---

## 変換処理の内容

1. **見出しの付け方** をnote向けに調整
2. **目次** を自動生成
3. **冒頭の要約文** を追加
4. 文体をX向けの短文スタイルからnote向けの丁寧な文体へ変換
5. 改行・段落構成をnoteの読了率に最適化
6. **画像プロンプトを適切な箇所に挿入**（下記ルール参照）

---

## 画像プロンプト挿入ルール

### 記法

```
<画像 横×縦px：[画像の内容説明]>
```

例：
```
<画像 800×500px：木材の断面の顕微鏡写真風のイラスト。高密度（細胞が詰まっている）と低密度（空隙が多い）の2種類を並べた比較図解>
```

### 挿入する場所

| 種類 | 挿入タイミング | サイズ |
|---|---|---|
| アイキャッチ | 記事タイトルの直下 | 1280×670px |
| セクション図解 | 比較・構造・仕組みを説明するH2見出しの直後 | 800×500px |
| 補足イラスト | 文章だけでは伝わりにくい概念の段落末尾 | 600×400px |

### アイキャッチのCTA（クリック率向上テキスト）

アイキャッチ画像にはCTAテキストを必ず重ねて記述する。サムネイルを見た瞬間に「これ自分の話だ」と感じさせるのが目的。

**CTA設計の3原則**

| 原則 | NG | OK |
|---|---|---|
| 断言しない | 「絶対読むべき」| 「これかもしれない」|
| 読者を呼ぶ、押しつけない | 「ギタリスト必見！」| 「音がこもる人へ」|
| 体験言語で書く | 「ピックアップ解説」| 「音がモコッとする原因」|

**CTAパターン5種**

| パターン | 例 | 効果 |
|---|---|---|
| A｜「〜な人へ」型 | 「チューニング狂いやすい人へ」| 読者の状況を名指しして呼び込む |
| B｜「正体」型 | 「トーンサックの正体」| 知的好奇心に刺さる |
| C｜「知ると変わる」型 | 「知ると音作りが変わる話」| 価値を予告する |
| D｜「なんとなく」型 | 「なんとなく使ってたあのつまみの話」| 「分からなくて当然」の安心感 |
| E｜シリーズ表示型 | 「連載第5回｜ピックアップ編」| 連載ファン化を促す |

**テキストの仕様**

- 文字数：15〜25字以内（サムネイルで読める限界）
- フォント：太めのゴシック系（視認性重視）
- 位置：画像の左下または中央下寄り
- 色：白文字＋薄い黒背景ストロークで視認性を確保
- サイズ：画像高さの10〜12%程度
- 記号：「」で括るか末尾に「→」を添えると視線誘導になる

**アイキャッチ画像プロンプトへの記述方法**

CTA内容を画像プロンプトの説明文に含める。

```
<画像 1280×670px：[背景・構図の説明]。画像左下に白太字で「[CTAテキスト]」と重ねたデザイン>
```

例：
```
<画像 1280×670px：エレキギターのボディ中央にピックアップが並んでいるアップの写真風イラスト。ミニマルなフラットデザイン、ダークトーン背景。画像左下に白太字で「音がモコッとする原因」と重ねたデザイン>
```

### 挿入する条件（以下のいずれかに該当する箇所）

- **比較が必要な箇所**：2つ以上の選択肢・素材・仕様を並べて説明しているとき
  - 例：アルニコ vs セラミック、パッシブ vs アクティブ
- **構造・断面・回路を説明する箇所**：パーツの内部や配置が関係する説明
  - 例：ピックアップの内部構造、コイルの巻き方、回路図
- **「見た方が早い」概念の箇所**：文字だけでは空間的なイメージが伝わりにくいとき
  - 例：ネックの角度、弦とピックアップの距離感
- **読者の視線をリセットしたい箇所**：長い文章ブロックが続いた後、新しいセクションへの切り替えとして

### 挿入しない条件

- 1記事に5枚を超える場合は優先度の低いものを削る
- 同じ種類の画像が連続する場合は間隔を空ける
- 「まとめ」「コメント誘導」などの締めセクションには入れない

### 説明文の書き方

- 誰が見ても同じ画像を生成できる具体的な描写にする
- 「〜風のイラスト」「〜の図解」「〜の断面図」など用途を明記する
- 色・雰囲気の指定が必要な場合は「モノクロ図解」「ミニマルなフラットイラスト」など添える
